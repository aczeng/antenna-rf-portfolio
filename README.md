# 项目经历

## 01｜欧姆区FET超宽带有源接收天线及稳定性优化

**项目时间：2026.06–2026.08**

设计圆盘单极子与欧姆区 NE3510M04 FET 一体化有源接收前端，利用FET高输入阻抗降低电小天线负载效应，实现宽带电压感知与阻抗转换。

针对天线、晶体管及寄生参数形成的高频反馈问题，引入 **25 Ω + 1 pF 频率选择性栅极阻尼网络**，并基于 HFSS 与 ADS 完成电磁和射频电路协同优化。

### 主要工作

- HFSS完成圆盘单极子、电流分布及远场性能分析
- ADS完成FET有源前端、偏置及稳定性分析
- 完成天线、电路及寄生参数联合优化
- 独立完成样机加工、器件焊接和偏置调试
- 完成VNA及微波暗室测试

### 关键结果

- **2 MHz–3 GHz：μ、μ′ > 1**
- 输出匹配覆盖 **2 MHz–2.3 GHz**
- 供电：**2.55 V**
- 功耗约：**55 mW**
- 接收增益与方向图测试：**0.4–2.2 GHz**
- 最大接收增益：**9.27 dBi**

**成果：第一作者论文投稿 IEEE Antennas and Wireless Propagation Letters（AWPL），目前在投。**

> 项目图示将陆续补充：天线结构、FET前端、稳定性曲线、S参数、样机及测试照片。

## 02｜WiFi多频段小型化共体双馈高隔离天线

**项目时间：2025.09–2026.04**

面向金属侧板屏蔽的复杂安装环境，设计共辐射体双馈双端口天线，在有限空间内实现 WiFi 多频段宽带覆盖。

通过引入隔离枝节调控表面电流路径，降低双端口之间的互耦。

### 主要工作

- HFSS天线结构设计及参数扫描
- Optimetrics结构优化
- 双端口互耦及隔离分析
- 表面电流分析
- 增益、效率及远场方向图分析

### 关键结果

以下为仿真结果。

- 工作频段：**2.4–2.5 GHz**
- 工作频段：**5.05–7.125 GHz**
- 双端口 **VSWR < 2**
- 工作频段内 **隔离度 > 20 dB**
- 辐射效率 **> 80%**
- 最大增益：**6.5 dBi**

> 项目图示将陆续补充：HFSS结构、S参数及代表频点表面电流。

## 03｜10 m级微波无线输能系统搭建与现场测试

**项目时间：2025.09–2026.03**

参与远距离微波无线输能系统搭建，通过发射天线与接收天线实现空间无线能量传输，并完成实验室联调及现场工程验证。

### 主要工作

- 参与发射端、接收端及天线系统连接与联调
- 完成发射与接收天线布设
- 完成无线链路测试及接收功率记录
- 完成测试数据整理与分析
- 赴柳州完成设备安装、系统调试及现场实测
- 配合处理现场设备集成及天线部署问题

### 关键实测结果

- 传输距离约：**10 m**
- 系统输入功率：**100 W**
- 接收端实测功率约：**1.5 W**

> 注：由于输入功率与接收功率位于不同系统位置，本项目不直接将二者换算为系统传输效率。

> 项目图示将陆续补充：系统链路、现场安装照片及测试结果。
