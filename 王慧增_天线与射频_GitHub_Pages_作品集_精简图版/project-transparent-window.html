项目目标

基于透明导电膜将多个广播及通信天线集成于汽车车窗区域，面向广播接收、蜂窝通信、WiFi及V2X等多制式需求。

本人工作

  • 完成多频带结构设计及仿真验证。
  • 通过参数优化分析各端口阻抗匹配、表面电流及远场特性。
  • 目前进一步开展端口互耦分析与高隔离解耦优化。

技术方法

采用车窗集成多端口结构，由不同辐射单元和电流路径共同实现多频段工作，并结合端口匹配、电流与远场分析迭代结构。
